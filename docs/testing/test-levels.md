# Test levels

Draft, 2026-11-02. Covers the 135 software requirements (S1–S11). Rule: test each requirement at the cheapest level that can really prove it.

| Level | Name | How it runs | Covers (examples) |
|---|---|---|---|
| L0 | Static / CI | Automatically on every push | S1.9, S2.2, S4.1, inspection cards that can be scripted; the rest on a review checklist |
| L1 | Unit | `cargo test` and Ceedling on a PC | S1.12 (every error code), S6.2–S6.4 (fan curve, hysteresis), S8.13, S10.3, S10.4 |
| L2 | Protocol | Reference frames generated by the C code, decoded in Rust | S5.9, S5.11, bad CRC or length |
| L3 | Pi with simulated MCU | Real Pi app, simulator on a virtual serial port replaying scripted scenarios | S2.4, S8.9, S8.12, S10.5, S10.6, S10.17, power loss, display and dashboard behaviour |
| L4 | Firmware on the bench | NUCLEO-G071RB with injected AFE values | S3 protection, timing and timeouts, one test per Table E limit |
| L5 | Full system | Real battery, fans and touchscreen | S3.15, S6.7, S7.4, E-stop, fan spin-up (D13) |
| Cloud | Website and upload | Separate staging environment, once TE IT approves external hosting (P1.7) | S11 |
